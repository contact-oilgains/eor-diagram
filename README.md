## Corrections to a post on EOR in LinkedIn

Original post: [lnkd.in/p/gdhQ-tMH](https://lnkd.in/p/gdhQ-tMH)


1. **"Natural Flow" appears twice.** The second one, under Secondary Recovery, is almost certainly a copy-paste error. Secondary recovery is waterflooding and immiscible gas injection, so that box should be something like "Waterflooding" or "Immiscible gas injection". "Pressure Maintenance" is also a purpose, not a method, and it duplicates what the box already says.
2. **"Artifical Lift" is misspelled.** It should be "Artificial Lift". "Pump gas lift etc." should read "Pump, gas lift, etc."
3. **"Natural Flow" under Primary Recovery is acceptable.** Primary recovery covers natural flow, which includes solution-gas drive, gas-cap drive and water drive, plus artificial lift.
4. **"N2 immiscible gas" is wrong or incomplete.**
   - N2 can be miscible at high pressure in light-oil reservoirs, so the label is misleading.
   - "Hydrocarbon miscible, CO2" is also unclear. A clearer label is "Miscible (hydrocarbon, CO₂, N₂) / immiscible gas".
   - Also use "miscible", not "miscibile" if the original has that spelling, and write CO₂ with a subscript.
5. **The Chemical label "Polymer surfactant/polymer" is garbled.** It should list the methods: polymer, surfactant, alkaline, and combinations such as ASP (alkaline-surfactant-polymer).
6. **Thermal is incomplete.** "Steam In-situ combustion." should be "Steam injection, in-situ combustion" (and optionally SAGD and cyclic steam stimulation). Drop the trailing period.
7. **The arrow from 'Primary Recovery' straight to 'Tertiary Recovery' is correct but unexplained.** It means EOR can be applied directly after primary recovery, skipping secondary. A short note on the arrow would stop readers from reading it as an error. The line also leaves Primary Recovery from an awkward point, so reroute it more cleanly.
8. **The "CONVENTIONAL" and "EOR" side brackets overlap in scope.**
   - CONVENTIONAL spans Primary and Secondary, which is correct.
   - The EOR bracket covers only the four Tertiary methods, which is fine.
   - The arrows point both ways with no clear start or end. Use brace-style brackets instead.

**Enhancements**

- **Terminology.** "Tertiary recovery" and "EOR" are often treated as synonyms, but EOR is the broader term, because it can start at any stage. The skipped-secondary arrow already implies this, so say it in a caption.
- **Missing methods.** Add a few that are now standard:
  - Gas: WAG (water-alternating-gas), foam.
  - Chemical: low-salinity waterflooding or "smart water", which is sometimes classed as chemical or as a hybrid method.
  - Thermal: electrical or electromagnetic heating.
- **Microbial (MEOR).** It has no sub-label while the others do. Add one, for example "Microbial flooding, biosurfactants".
- **Caption.** "Oil Recovery Mechanisms" is imprecise, because these are recovery *stages and methods*. "Oil recovery stages and EOR methods" is better. It also cites no source.
